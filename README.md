# City Notes — Advanced CSS Assignment 2

**Student:** Aisu Nurzhan

A responsive three-page city-themed site built with plain HTML and CSS. All nine illustrations are stored locally in `assets/`.

## Run locally

Open `index.html` in a browser. Use the navigation links to visit the other pages. No installation or build step is needed.

## Pages and requirements

| Page | Required features | CSS file |
| --- | --- | --- |
| `index.html` | Flexbox logo/navigation and three equal-height cards with images, text, buttons, gaps, and hover movement | `styles/flex.css` |
| `grid.html` | Header/sidebar/main/footer positioned with named grid areas; nine-image Grid gallery with caption hover | `styles/grid.css` |
| `portfolio.html` | Flexbox header; Grid projects/sidebar; Flexbox within project cards; full-width footer | `styles/portfolio.css` |

Every page includes navigation to the other pages. Media queries adapt the layouts to narrow screens; gallery captions also appear on touch devices. Links and image alternatives are included.
